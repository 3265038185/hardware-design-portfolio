# 基于 STM32G4 + AD9850 的 DDS 信号源设计

## 1. 设计目标

基于 STM32G4 系列开发板和 AD9850 DDS 模块，实现一台参数可调的实验信号源：

- 正弦波：1 kHz–40 MHz，频率步进 1 kHz
- 脉冲/方波：频率可调，占空比 0–100%
- 自动扫频：1 kHz–40 MHz，步进 1 kHz，步进间隔 100 ms，到边界自动反向
- 所有参数（频率、波形类型、占空比、工作模式）实时显示在 TFT 上
- 4 个独立按键本地调节，同时支持 USART1 远程命令
- 采用前后台结构：主循环轮询任务，串口空闲中断 + DMA 完成后台接收

> AD9850 本身只能输出正弦波。本设计中的“脉冲波”通过界面模拟并预留 PWM 扩展接口；硬件上可外接定时器 PWM 通道和模拟开关，在正弦与方波之间切换。

## 2. 系统结构

```mermaid
flowchart LR
    KEY[4 个按键] --> MCU[STM32G431]
    UART[USART1<br/>115200 8N1] --> MCU
    MCU -->|模拟 SPI| DDS[AD9850 DDS]
    MCU --> LCD[2.4" TFT<br/>ILI932X]
    DDS --> OUT[正弦波输出]
    MCU -.预留 PWM.-> PWM[方波/PWM 输出]
```

主循环 `main_pros` 轮询调用：

- `key_scan()`：按键消抖、更新频率/占空比/扫频状态
- `uart_handle()`：解析串口命令
- `Sig_Out()`：根据扫频标志更新 AD9850 频率
- `lcd_show()` / `para_show()`：刷新显示

## 3. 硬件设计

| 模块 | 型号 / 连接 |
|------|-------------|
| 主控 | STM32G431RBT6，HSE 24 MHz，PLL 倍频至 170 MHz |
| DDS | AD9850 模块，30 MHz 有源晶振 |
| DDS 控制 | DATA→PA7，CLK→PA5，FQ→PA6，RST→PA4 |
| LCD | 2.4 寸 320×240 TFT，ILI932X，8 位并口；数据 PC0–PC7，RS→PB8，RW→PB5，EN→PB9，CS→PA8 |
| 按键 | KEY1→PB0，KEY2→PB1，KEY3→PB10，KEY4→PC4 |
| LED | 8 个 LED + 74HC373 锁存；数据 PC8–PC15，锁存 LED_LOCK→PB2 |
| 串口 | USART1_TX→PA9，USART1_RX→PA10；CH340E / MAX3232 电平转换 |
| 电源 | USB 5 V → AMS1117-3.3 → MCU / DDS / LCD |

### 关键设计点

- **AD9850 时序**：控制引脚配置为推挽输出、`GPIO_SPEED_FREQ_VERY_HIGH`，保证边沿陡峭；按 40 位时序写入频率控制字和控制字节，最后由 FQ 上升沿锁存。
- **LCD 并行总线**：GPIOC 在输出/输入模式间动态切换；写操作输出，读 ID/GRAM 时输入，分别由 `LCD_BusOut()` / `LCD_BusIn()` 处理。
- **按键上拉**：部分使用内部上拉，部分使用外部上拉，保证未按下时为高电平。
- **LED 锁存**：先写 PC8–PC15，再给 PB2 一个低脉冲，把状态锁存到 74HC373，避免 MCU 直接承担 8 路 LED 电流。

## 4. DDS 频率控制

AD9850 内部为 32 位相位累加器，输出频率：

\[
f_{out} = \frac{FTW \times f_{clk}}{2^{32}}
\]

其中 `FTW` 为频率控制字，`f_clk` 为参考时钟（30 MHz，或 6 倍频后的 180 MHz）。程序根据目标频率计算 FTW，再通过模拟 SPI 写入 4 个字节及控制字（倍频使能、相位），最后产生 FQ 上升沿锁存。

## 5. 扫频实现

`Sig_Out()` 使用 `HAL_GetTick()` 记录上一次步进时刻：

```text
每 100 ms：
  若方向向上：频率 += 1000 Hz
  若方向向下：频率 -= 1000 Hz
  到达 1 kHz 或 40 MHz：方向取反
  调用 AD9850_SetFreq() 更新输出
```

非阻塞延时保证扫频期间按键、串口和显示仍然响应。

## 6. 人机交互

### 按键

- 20 ms 软件消抖，下降沿触发
- 功能：扫频开关、波形切换、频率 +1000 Hz、占空比 +5%

### 串口命令

USART1：115200 bps、8N1；DMA 接收，空闲中断判断一帧结束。

| 命令 | 作用 |
|------|------|
| `SETF:<频率>` | 设置频率 |
| `SETT:<类型>` | 设置波形类型 |
| `SETS:<占空比>` | 设置占空比 |
| `ASKS` | 查询当前状态 |

### 显示

- 8 位 8080 并口驱动 ILI932X / UC8230
- 不同模式使用不同背景色：正弦黑、脉冲黄、扫频绿
- 实时显示频率、波形、占空比、工作模式

## 7. 测试结果

使用 RIGOL DS1054Z 数字示波器测量。

### 正弦波

| 设定频率 | 实测频率 | 相对误差 | Vpp | 结论 |
|----------|----------|----------|-----|------|
| 1 kHz | 1.00 kHz | 0.00% | 1.00 V | 合格 |
| 300 kHz | 300.3 kHz | 0.1% | 1.086 V | 合格 |

测试点频率误差均小于 ±0.15%；幅值随频率升高略有下降，符合 DDS 输出特性。

### 脉冲/方波

| 设定频率 | 实测频率 | 相对误差 | Vpp | 占空比 | 结论 |
|----------|----------|----------|-----|--------|------|
| 1 kHz | 1.00 kHz | 0.00% | 6.16 V | 50% | 合格 |
| 370.002 kHz | 370.4 kHz | 0.10% | 6.12 V | 50% | 合格 |
| 1 kHz | 1.00 kHz | 0.00% | 6.24 V | 72% | 合格 |

### 扫频

- 1 kHz–40 MHz，步进 1 kHz，驻留 100 ms
- 到边界自动反向，频率连续、无明显跳变
- 扫频期间按键仍可响应

## 8. 不足与改进

- AD9850 不能直接输出方波；后续可改用 AD9833，或外接高速比较器把正弦整形为方波。
- 频率步进固定为 1 kHz，低频段相对步进偏大；可增加粗调/细调模式。
- 扫频间隔固定 100 ms；可做成用户可调参数，并增加起止频率设置。
- 当前为前后台轮询结构，后续可以引入 RTOS 把显示、按键、通信拆成独立任务。
