# PCB Gerber 文件

| 目录 | 板卡 | 层数 | 说明 |
|------|------|------|------|
| `51-mcu-core-board/` | 51 单片机核心板 | 2 层 | 最小系统 + 排针引出 |
| `stm32-dev-board/` | STM32 开发板 | 2 层 | 含飞针测试文件 |
| `usb-hub/` | USB HUB | 2 层 | USB 扩展板 |

每个目录都是解压后的 Gerber + 钻孔文件，可直接打包给 PCB 厂。打样前请用 Gerber 查看器检查板框、层叠和钻孔。

> EDA 源工程未包含；这里只有制造文件。
